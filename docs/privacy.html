Avila Auto Publisher

Privacy Policy

Last updated: August 20, 2026

Avila Auto Publisher ("the Tool") is an internal automation tool operated solely by Aurelio Avila to schedule and publish short-form video content to social media platforms on behalf of properties he personally owns and operates. This policy explains what data the Tool accesses and how it is used.

Who operates this Tool

The Tool is developed, deployed, and used exclusively by its owner. It is not offered to, installed by, or accessible to any third party or member of the public.

What data is accessed

To publish content, the Tool authenticates directly with the operator's own social media accounts using platform-provided OAuth tokens. It accesses only the minimum data required to upload video content, read publishing status, and read basic performance metrics (views, engagement) for the operator's own posts. The Tool does not access, collect, or process data belonging to any other user of the connected platforms.

What data is stored

OAuth credentials are stored locally on the operator's own machine and are never transmitted to any third party. Generated video files, captions, and scheduling metadata are stored locally and are used only to drive the publishing process.

Data sharing

No data is sold, rented, or shared with third parties. The only data transmission that occurs is between the Tool and the official APIs of the social media platforms it publishes to, for the sole purpose of publishing the operator's own content.

Data retention

Locally stored credentials and metadata are retained for as long as the Tool remains in active use and are deleted when no longer needed.

Contact

Questions about this policy can be directed to the operator via the contact details on file with the relevant platform's developer portal.
